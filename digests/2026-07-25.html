What, Where, and How: Disentangling the Roles of Task, Language, and Model in Code Model Representations

Comparing Qwen2.5-Coder-7B and DeepSeek-Coder against Python and Rust, the authors find that which grammatical concepts earn dedicated circuits is set by the task (models agree on this), while where those circuits sit in the network and how they develop across layers is set by the specific model - and Rust concepts get 2-3x more dedicated circuitry than Python equivalents in both models.

A Unified Moral-Value Dataset for Instruction Tuning

The authors merge existing moral-value datasets into a single instruction-response corpus purpose-built for value alignment, since general instruction-tuning sets aren't designed around moral scenarios. Mixing it with general-task data preserves general capability while improving value-oriented task performance, with the mixing ratio shaping the tradeoff.
