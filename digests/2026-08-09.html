OpenAI pauses part of Astra's development after it crosses a "critical" cybersecurity threshold

An internal review found OpenAI's unreleased Astra model could independently identify and chain zero-day exploits against hardened real-world systems, enough that OpenAI can't rule out Critical capability level under its Preparedness Framework. The company is halting internal work that doesn't meet stricter security controls and is bringing in government agencies and outside safety groups to stress-test the model before any release.

Nvidia open-sources NOOA, collapsing an AI agent into a single Python class

NOOA (Nvidia Object-Oriented Agents) is an Apache 2.0 framework where an agent's state, actions, and prompts are just fields, methods, and docstrings on one class — deterministic code stays deterministic, while methods left unimplemented get completed at runtime by an LLM loop. Nvidia reports 82.2% on SWE-bench Verified with GPT-5.5 using roughly half the tokens of competing harnesses, though it notes its sandboxing is defense-in-depth, not a hard containment boundary.

Paper: teaching a "harness engineer" to rewrite an agent's runtime from its own failures

Harness-R1 trains a dedicated model, via online reinforcement learning, to read batches of a frozen agent's failed trajectories and write reusable runtime patches — validated, compiled into sandboxed hooks, and scored by rerunning the same tasks. Applied to a frozen Qwen3.5-9B agent across WebShop, ALFWorld, and DBBench, it lifted task success by an average of 9.3 percentage points without touching the underlying model.

Paper: for messy documents, reading beats embedding

On a 780-page government financial report, 86.8% of content lines are table rows whose figures inherit units from a header a median of 13 lines above — exactly the kind of structure chunk-and-embed retrieval destroys. The authors' READ system instead has an agent search, navigate, and read the raw document via deterministic operations exposed over MCP, answering 58.8% of 51 verified questions versus 15.7% for dense retrieval, with a fully replayable audit trail.
