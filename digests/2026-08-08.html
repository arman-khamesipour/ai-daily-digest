Paper: routing between web-agent observation modes is hardest exactly where it matters most

Testing six ways web agents can observe a browser (text, pixels, or both) across eight site-model combinations, researchers find each mode solves tasks the others miss, and the best choice reverses across task sets. Because routing supervision comes from success signals, it's least learnable precisely where switching modes would help most — though sending only the hardest tasks to a cheaper mode still cuts cost 9.5-30.6% at no loss in success.

Paper: teaching LLMs to selectively trust context, not just resist it

Training models to ignore misleading external context can produce models that ignore all context, useless when it's actually trustworthy. The authors introduce MIST, a benchmark testing four context conditions per item, and SCOPE, a preference-optimization method that targets only the failures where misleading context flips a correct answer wrong — cutting that failure rate while preserving accuracy on clean or correct context.
